# SAR — сравнение оборудования и подбор под объект

Внутренний инструмент для дистрибьютора сетевого оборудования и видеонаблюдения
(TP-Link/Omada, Vitek, Hikvision) в Узбекистане. Помогает быстро отвечать
клиентам, которые приходят со списком оборудования конкурентов
(Ruijie, Tenda, Ubiquiti/UniFi, MikroTik, Dahua и др.).

## Возможности

- **Сравнение / КП** — вбиваете товары конкурента из списка клиента, система
  подбирает аналог из вашего каталога, показывает характеристики бок о бок,
  плюсы/минусы, цену, наличие на складе. Список формируется в коммерческое
  предложение, которое можно распечатать или сохранить в PDF (кнопка «Печать»).
- **Подбор по объекту** — упрощённый аналог TP-Link Omada Designer: по
  площади, числу этажей, материалу стен и числу пользователей рассчитывает
  ориентировочное количество точек доступа, коммутаторов, роутер, контроллер
  и, при необходимости, камеры/NVR.
- **Мой каталог** — свои товары (TP-Link, Vitek, Hikvision) с ценами, остатками,
  характеристиками, плюсами/минусами. Редактируется прямо в интерфейсе.
- **Конкуренты** — каталог оборудования конкурентов с привязкой к своему аналогу.

Все данные хранятся в localStorage браузера и стартуют с демо-заполнением —
отредактируйте цены/остатки под свой склад. Кнопка «Сбросить к демо» в каждом
каталоге возвращает исходные примеры.

## Разработка

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # проверка типов + сборка
npm run lint     # oxlint
```
